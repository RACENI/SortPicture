# 📸 사진 정리 프로그램 (SortPicture)

여러 사진 메타데이터(EXIF)를 기반으로  
사진을 자동 분류·정리해주는 데스크톱 프로그램입니다.

촬영 시간, 위치(GPS) 등의 정보를 활용하여  
사용자가 원하는 기준으로 사진을 체계적으로 관리할 수 있도록 설계되었습니다.

---

## ✨ 주요 기능

- 📅 촬영 시간 기반 사진 정리
- 🌍 GPS(위치 정보) 기반 사진 분류
- 🗂 다양한 메타데이터 확장을 고려한 구조 설계
- 🧭 사용자 지정 장소 선택 기반 분류
- 🔐 Google API Key 저장 기능

---

## 🧩 프로그램 개요

사진 파일의 EXIF 메타데이터를 분석하여  
연도 / 월 / 위치 / 사용자 지정 장소 등  
다양한 기준으로 자동 정리합니다.

GPS 정보가 포함된 사진의 경우,  
사용자가 직접 장소를 선택하여 분류할 수 있습니다.

동일한 장소가 중복될 경우,  
보다 좁은 행정 단위를 우선하여 분류합니다.

## 📂 프로젝트 구조 (요약)

```text
SortPicture
 ├─ Core            # 메타데이터 분석 및 분류 로직
 ├─ GPS             # GPS 기반 위치 처리
 ├─ UI              # 사용자 인터페이스
 ├─ Utils           # 공통 유틸리티
 └─ Config          # API Key 및 설정 관리
```
※ 구조는 향후 기능 확장을 고려하여 지속적으로 개선 예정입니다.
