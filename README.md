# 📸 사진 정리 프로그램 (SortPicture)

여러 사진 메타데이터(EXIF)를 기반으로  
사진을 자동 분류·정리해주는 데스크톱 프로그램입니다.

촬영 시간, 위치(GPS) 등의 정보를 활용하여  
사용자가 원하는 기준으로 사진을 체계적으로 관리할 수 있도록 설계되었습니다.

---

## ✨ 주요 기능

- 📅 촬영 시간 기반 사진 정리
- 🌍 GPS(위치 정보) 기반 사진 분류
- 🗂 다양한 메타데이터 확장을 고려한 구조 설계
- 🧭 사용자 지정 장소 선택 기반 분류
- 🔐 Google API Key 저장 기능

---

## 🧩 프로그램 개요

사진 파일의 EXIF 메타데이터를 분석하여  
연도 / 월 / 위치 / 사용자 지정 장소 등  
다양한 기준으로 자동 정리합니다.

GPS 정보가 포함된 사진의 경우,  
사용자가 직접 장소를 선택하여 분류할 수 있습니다.

동일한 장소가 중복될 경우,  
보다 좁은 행정 단위를 우선하여 분류합니다.

## 📂 프로젝트 구조 (요약)

```text
SortPicture
 ├─ Core            # 메타데이터 분석 및 분류 로직
 ├─ GPS             # GPS 기반 위치 처리
 ├─ UI              # 사용자 인터페이스
 ├─ Utils           # 공통 유틸리티
 └─ Config          # API Key 및 설정 관리
```
※ 구조는 향후 기능 확장을 고려하여 지속적으로 개선 예정입니다.

## ▶ 실행 방식 및 폴더 규칙

- 프로그램 실행 위치 기준으로 `working` 폴더를 생성해야 합니다.
- 정리할 사진 파일들은 모두 `working` 폴더 내부에 위치해야 합니다.
- 프로그램 실행 시 `working` 폴더 내의 파일들을 대상으로 정리가 진행됩니다.

예시:
```text
프로그램실행경로
├─ SortPicture.exe
├─ working
│ ├─ IMG_0001.jpg
│ ├─ IMG_0002.jpg
│ └─ IMG_0003.jpg
```

---

## 📁 정리 결과 생성 위치

- 사진 정리 결과는 **프로그램 실행 디렉터리 하위**에 자동 생성됩니다.
- 정리 기준(날짜, GPS, 사용자 지정 장소)에 따라  
  폴더가 자동 생성되고 사진 파일이 이동됩니다.
- 원본 파일은 `working` 폴더에서 이동됩니다(복사 아님).

---

## 🌍 GPS 기능 사용 시 주의 사항 (Google API)

- GPS 기반 사진 정리를 사용하려면  
  **Google Geocoding API**가 활성화된 Google API Key가 필요합니다.
- Google API는 **무료 할당량이 존재하지만**,  
  사용량에 따라 과금이 발생할 수 있습니다.
- API Key는 프로그램 설정 파일(`config.json`)에 저장됩니다.

⚠️ **주의**
- `config.json` 파일은 개인 API Key를 포함하므로  
  **공개 저장소에 커밋하지 않도록 주의하십시오.**
- API 사용 정책 및 과금 여부는 Google 정책을 반드시 확인하시기 바랍니다.
